PROJETO - Banco de Dados

Aplicativo simples desenvolvido em Java para Android Studio, usando XML na interface e SQLite para guardar os dados.

O sistema permite:
- Cadastrar uma pessoa informando nome e idade;
- Consultar uma pessoa pelo nome;
- Atualizar a idade cadastrada;
- Excluir uma pessoa pelo nome.

Tecnologias utilizadas: Java, XML, Android Studio e SQLite.

Arquivos principais:
- res/layout/activity_main.xml: campos, botões e mensagens da tela;
- java/com/example/projetocrud/MainActivity.java: ações dos botões e validações;
- java/com/example/projetocrud/BancoHelper.java: criação da tabela e operações no banco de dados.

Para executar, abra o projeto completo no Android Studio e execute em um emulador ou celular conectado. Esta pasta contém os arquivos-fonte presentes no pacote recebido; caso seu projeto-base tenha arquivos Gradle ou manifest separados, mantenha-os junto com estes arquivos.
